# 西洋骨牌 · 双人 / 三人牌桌 2D 可玩版

这是独立的双人 / 三人西洋骨牌 2D Web 游戏目录，不修改旧的地主、扑克接龙或麻将接龙页面。

## 预览

直接打开 index.html，或在本目录启动静态服务器后访问：

    http://127.0.0.1:<端口>/

当前页面可在开始界面选择双人或三人牌桌：你在左下，双人时顶部居中显示 1 名 AI，三人时上方左右显示 2 名 AI。点击“开始游戏”后，点击手牌只会选中；把手牌拖到发光链端，松手才会出牌。每回合无牌可接时最多抽 1 张，仍不能接则出现“跳过”按钮。牌链保持牌面尺寸并在桌面自动转弯，不缩放、不叠压。

## 目录文件

- index.html：完整可玩的 2D 双人 / 三人骨牌游戏，含重排后的双栏入口 UI 与 5 套牌面皮肤
- wireframe-v2.html：确认后的 Switch 式结构原型留档
- prototype-spec.md：页面地图、状态矩阵、设计决策和待确认问题
- requirements-ledger.yaml：需求台账、状态卡、资源与 QA 记录
- 项目已内置一份可独立上传的运行资源，位于 `公共资源素材/kenney_domino-pack/`；公共总目录仍保留给其他项目共用

## 资源说明

- 骨牌：项目目录 `公共资源素材/kenney_domino-pack/PNG/` 下的 Light、Dark、Gingerbread、Hearts、Stars（界面显示为“莓果红”）五套 2D PNG；压缩包内许可证为 CC0。
- 换肤只替换骨牌图片（包括入口预览、牌链和手牌），牌桌、背景、头像、按钮、提示框和布局始终保持同一套 UI。
- 界面：按钮和交互音效引用项目目录 `公共资源素材/kenney_interface/`（页面：https://kenney.nl/assets/tag:interface），仅保留页面实际引用文件。
- 头像：本轮使用文字头像占位，不引入 3D 角色或外部 IP。

## 当前范围

当前已包含双六牌组、双人 / 三人各发 5 张、5 套牌面皮肤切换、最大对子开局、两端匹配、对子垂直主链、每回合单次抽牌、跳过、AI 回合、阻塞判定、胜负结算、结果回看和再来一局。当前仍是本地 AI 原型，不会伪装成跨设备联机。

## 联机邀请码需要什么

“发一个邀请码，别人输入后进房间”可以做，但静态 HTML 本身不能让两台设备互相同步。正式联机需要：

- 一个可公网访问的房间服务（HTTPS/WSS），负责生成短邀请码、创建 / 加入房间和掉线重连；
- 服务端权威牌局状态（洗牌、发牌、轮到谁、合法出牌校验），客户端只发送操作；
- 前端的创建房间、输入邀请码、复制 / 分享链接和房间满员提示；
- 一台部署服务端的主机或云函数，以及正式域名和 HTTPS 证书。

本版不加入联机房间和邀请码功能，继续保持打开即玩的本地 AI 原型。
